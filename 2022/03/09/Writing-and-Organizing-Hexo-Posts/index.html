2. Organizing Content

Categories and Tags

At the top of each post file, include YAML front-matter:

  • Categories: hierarchical (e.g., Tech → Web → Hexo).
  • Tags: free-form keywords.

File Structure

  • source/_posts/ → Blog posts
  • source/_drafts/ → Blog drafts
  • source/about/ → About page
  • themes/ → Theme configuration
  • scaffolds/ → Default templates for new posts

3. Enhancing Blog Management

  • Use excerpts: Add <!-- more --> in posts to separate summary from body.
  • Assets per post: Enable post_asset_folder in _config.yml to manage images/files alongside posts.
  • Plugins: Use plugins like hexo-generator-sitemap and hexo-generator-feed for SEO.
