Theme Resources

There are two places I would go to discover nice Hexo themes:

  • Hexo official website
  • GitHub query
    • add some filter criterias (e.g. query: “Hexo theme stars:>1000 pushed:>2023-01-01”)
    • it will be better to filter out the ones that are not maintained anymore (potential compatibility issues)
